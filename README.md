📊 Blinkit Sales Performance Dashboard
📌 Project Overview

The Blinkit Sales Performance Dashboard is an interactive Power BI data analytics project designed to analyze sales performance, outlet characteristics, product categories, and customer-facing metrics.

The dashboard uses Power BI and DAX to transform raw retail sales data into meaningful business insights through interactive KPIs, charts, filters, and performance tables.

The project demonstrates how a Data Analyst can use data modeling, DAX measures, visual analytics, and business-oriented dashboard design to monitor and understand retail sales performance.

Note: The figures shown below are based on the dashboard snapshot included in this project. They represent the data available in the project and should not be interpreted as current official Blinkit business figures.

🖼️ Dashboard Preview

🎯 Project Objectives

The primary objectives of this dashboard are to:

Analyze overall sales performance
Track key sales KPIs
Understand outlet-level performance
Compare different outlet sizes and locations
Analyze product/item-type performance
Compare Low Fat and Regular products
Analyze sales trends based on outlet establishment year
Evaluate average ratings and item visibility
Provide interactive filtering for business analysis

1. Outlet Establishment Analysis

The Outlet Establishment line/area chart shows total sales across outlet establishment years.

Key observations from the dashboard:

Sales increase substantially toward 2018.

🚀 How to Run the Project
1. Clone the Repository

2. Download/Install Power BI Desktop

Open the project using Power BI Desktop.

3. Load the Dataset

4. Perform Data Preparation

Use Power Query to:

Check data types
Handle missing values
Clean columns
Transform data where required
5. Create DAX Measures

Create the required measures for:

Total Sales
Average Sales
Number of Items
Average Rating
Category analysis
Outlet analysis
6. Open the Dashboard

Use the slicers and visualizations to interactively analyze sales performance.
